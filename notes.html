試作を開く画面の一覧

エスピクトスクール アプリ 試作 — 考えたこと

ひとことで：「つぎの一歩が、いつも見える。」 利用者は「いま何をすればいいか」で迷わない。職員は「声をかけるべき人」がすぐ分かる。運営は「確認と返事」をすばやく、やさしく。

0. 開き方

  • out/index.html をブラウザで開くだけで動きます（サーバー不要。CSS・JS・データを1つのファイルにまとめてあります）。
  • 入口で 利用者（受講者）／事業所の職員／運営 の3つから選びます。
  • 全画面の写真：out/shots/index.html（スマホ幅 390px と PC 幅 1440px）。画像そのものは out/shots/sp/・out/shots/pc/。
  • このメモをスマホで読む：out/notes.html
  • 押したり出したりしたことは、この端末のブラウザの中だけに保存されます。入口か設定の「最初にもどす」で、はじめの状態に戻ります。
  • 入口の「試作の時計」で、朝 9:52（授業の前）／10:24（授業LIVE中）／15:40（一日のおわり） を切りかえられます。時間によって、利用者の「つぎの一歩」や職員の画面の様子が変わります。

3つの画面は つながっています（試してほしい流れ）

やること どうなるか
A 利用者で課題を開いて「これで提出する」 運営の「提出チェック」の いちばん上に「いま届いた」で出る → 運営が「OK」 → 利用者の課題のチャットに返事、お知らせ、課題の表の色が変わる
B 利用者で「こまった？」→「職員さんを呼ぶ」 職員の画面の いちばん上に知らせが出る → 職員が「対応した」 → 利用者の画面に「職員さんが気づきました」
C 利用者で ぴくとに「つらい」「ねむれない」などと書く ぴくとは本人に「職員さんに知らせたよ」と伝え、職員の画面に緊急の知らせが出る（「対応した」を押すまで消えない）

PC なら、2つのタブで別々の入口を開いておくと、もう片方のタブにすぐ反映されます。

1. だれの、どんな困りごとを解くか

利用者（受講者）

事業所に通い、デジタルのスキルを学んで、実際の仕事（案件）にも取り組む人。パソコンが得意でない人、文字を読むのが苦手な人、集中が続きにくい人もいます。主に PC、ときどきスマホ。

  • 何から手をつければいいか分からない（メニューが多い、課題がずらっと並ぶ）
  • 長い文を読むのがつらい（指示書、返事）
  • 質問しづらい・助けを呼びづらい（手をあげるのが苦手、まわりに気をつかう）
  • 出し方が分からない／失敗がこわい（フォームの項目が多い、出したら終わり、と感じる）
  • 時間の見通しが立たない（授業はいつ？ あとどれくらい？ いつ休む？）

事業所の職員（支援員）

IT の専門家ではない。自分の事業所の利用者だけを見る。毎日の声かけと、記録・報告が大事な仕事。

  • 誰に声をかければいいか、すぐに分からない（全員の画面を見て回れない）
  • 大事な知らせを見のがすのがこわい
  • 記録や月の報告の手間が大きい

運営（エスピクトスクール）

教材・授業・課題・案件を出し、提出物を確かめ、返事をする。人数が増えるほど、確認と返事が重くなる。

  • 1件ずつ返事を考えるのが重い／言葉のむずかしさにばらつきが出る
  • 課題を「級×作り方」で何本も作るのが手間
  • データの表記ゆれやミスに気づきにくい

2. 今のよくあるアプリと、何が違うか

よくあるアプリ この試作
メニューが多く、何をするかは自分で探す ホームに 「つぎの一歩」が1つだけ大きく出る。押せばすぐ始められる。授業の時間には自動で「授業に入る」に変わり、「授業のあとは：〇〇」も出る
課題が一覧でずらっと並ぶ 同じテーマの課題を 「作り方 × 級」の表で1枚に（10月のブログ記事9つ）。できた／確認中／とりくみ中／返事あり が色とことばで分かる
提出フォームの項目が多い 出し方は 「質問する」と「これで提出する」の2つだけ。出す前にチェックの残りを、責めない言い方で知らせる（「このまま出しても大丈夫」）
文字が小さく、読むのが前提 文字3段階・ふりがな・読み上げ・くっきり表示・ダーク・動きをへらす。どの画面にも「よむ」ボタン。言葉は、やさしい日本語
AI は何でも答える ぴくとは合否を言わない。ヒントと「やることを小さく分ける」が得意。体や気持ちのつらいことばには、職員さんへ知らせる
助けを呼ぶのは、手をあげるしかない どの画面にも 「こまった？」。ぴくとに聞く／職員さんを呼ぶ／ひと休みする が1回で選べる
職員の画面は数字の表 「声かけが必要かも」が先に出る（止まっている・つかれぎみ・まだ来ていない・はじめての人）。緊急の知らせは「対応した」まで いちばん上
運営は1件ずつ返事を書く AI の判定と返事の下書き → 「OK／直してOK／出さない」の3択。やさしい日本語チェック、キーボード操作、取り消し。OK の時だけ利用者に届く
3つの画面がばらばら 利用者の提出 → 運営のチェック → 利用者に返事、呼び出し → 職員、がつながっている
連続ログインや順位で追い立てる くらべない・せかさない。「きのうの自分より、ひとつ進めばOK」。休けいは「50分たったら、やさしくすすめる」
お金・工賃を目標に見せる 収入・工賃の表示はしない。案件は「やってみたい」で手をあげ、職員・運営と相談して決める

3. 画面ごとの狙い

入口

  • 3つの入口を大きなカードで。各入口で「何ができるか」を3〜4行で。
  • 「3つの画面は つながっています」で試す順番を案内。試作の時計と「最初にもどす」もここに。

利用者（受講者）

骨組み：スマホは下に5つのタブ（きょう／授業／教材／課題／ぴくと）。PC は左のメニュー。上のバーには 「こまった？」（黄色）・お知らせ がいつもある。PC では日付・時刻と出席の状態も上に出る。

画面 狙い
きょう いちばん大事な画面。①「来たら、まず出席する」②授業LIVE までの分数 ③つぎの一歩（1つだけ、大きく。動画なら「のこり約5分」、課題の何番目か）④運営からの返事 ⑤きょうの予定 ⑥10月にやったこと（くらべない言い方）。「ほかのことをする」で、選びたい人は選べる。自分のジャンルの授業LIVE中は、つぎの一歩が「授業に入る」（ピンク）に変わり、「授業のあとは：〇〇」も出る。つづけて50分たつと「少し休みませんか？」（授業中は出さない）
出席・調子 「出席する」→ きょうの調子（げんき／ふつう／つかれぎみ。職員だけが見る、答えなくてもOK）。休けい中は取り組み時間に数えない。おわる時は「どうだった？」を任意で
こまった？ ぴくとに聞く／職員さんを呼ぶ（どんなことか任意で選べる）／ひと休み。呼んだあとは上に帯が出て、職員が対応すると「気づきました」に変わる。取り消しもできる
授業LIVE 時間割（曜日タブ、きょうの印、あなたのジャンル）、アーカイブ（catalog の実際の「Web制作｜1時間目」などを日付ごと）。10分前から入れる
授業の教室 「わかった／もう一回／手をあげる」の大きなボタンで、声を出さずに参加できる。質問は名前を出さずに送れる。字幕つき。始まる前は「音が聞こえるか ためす」
教材ライブラリ 「つづきから見る」「いまの課題で使う教材」が先。シリーズは進みぐあいのバーつき。さがす機能
動画を見る 「この動画で やること」を3行で（読み上げつき）。字幕・速さ・10秒もどる。「見おわった」。つぎの動画と、この動画を使う課題へ
課題 「いま取り組んでいる課題」→「10月のブログ記事（作り方3×級3）の表」→「10月の指示書」→ はじめてコース・前の月はたたんでおく。しぼりこみ（とりくみ中／まだ／出した／できた）
課題のページ（指示書） 読む → 作る → 出す の3段。「やること」3行（よむ・もっとかんたんに）→ できあがりの見本 → 進め方（いまここ・使う動画）→ できたらチェック → 素材 → 出し方。下には 「質問する」「これで提出する」の2つだけ。指示書は紙に印刷もできる
ひとつずつ見る 集中が続きにくい人のために、いまの段階だけを大きく1枚で見せる。「できた！つぎへ」で1つずつ進み、ぜんぶ終わると「これで提出する」へ。ほかの情報は見せない
質問する よくある質問を押すだけでも聞ける。ぴくとは課題の中身を知っていて、その課題のことで答える
これで提出する ①出すもの（URL／画像／動画／文）②ひとこと（ことばのきっかけつき）③さいごの確認（チェックの残りを、責めずに）→「出せました！」。返事はチャットに届くと伝える
課題のチャット 運営の返事（緑）・ぴくと（白）・自分（青）・「出しました」の記録。ここからも ぴくとに聞ける
ぴくと ぴくとの「やくそく」を見えるところに。答えには、ステップの番号、動画へのボタン、休けいボタン。課題をえらばずに聞いても、いま取り組んでいる課題のこととして答える（「つぎに何をすれば？」→「ブログ講座⑤をつづきから見る」）。声で入力（対応ブラウザ）、答えを自動で読み上げる設定も
作ったもの 運営が確認した作品のギャラリー。「くふうした所」と「運営からのことば」をいっしょに残す
案件ボード 受けられる仕事。条件を満たしているか（受けられます／条件）、量・期間・たのむ人。お金の話はしない。「やってみたい」は相談のはじまり
お知らせ きょう／これまで。押すとその場所へ。まだ読んでいない印
見やすさ・設定 文字の大きさ3段階、明るい／ダーク、くっきり表示、ふりがな（漢字の上にだけ。送りがなには つけない）、動きをへらす、休けいのおしらせ、読み上げの速さ、ぴくとの答えを自動で読む。見え方の見本つき
出席のきろく きょうの流れ、10月のカレンダー（長さで濃く）、1日ごとの時間のグラフ（表でも見られる）

事業所の職員（支援員）

骨組み：スマホは下に5つのタブ（きょう／利用者／出席／月の報告／予定）。PC は左のメニュー。緊急の知らせは、どの画面でも上に赤い帯で残り、そこからも「対応した」を押せる。

画面 狙い
きょうの様子 ①緊急の知らせ（赤：ぴくとへの相談に つらいことば／黄：職員さんを呼ぶ）。本人のことば・すすめる対応・「この人の様子」。「対応した」を押してメモ（声をかけた・別室で話を聞いた など、えらぶだけでもOK）を残すまで消えない ②来ている・まだ・休み・止まっている・きょうの提出・授業LIVE中 の6つの数 ③声かけが必要かも（20分以上 手が止まっている、つかれぎみ、来る時間をすぎた、はじめての人）と、その理由。「声をかけた」で記録 ④みんなの様子（PCは表、スマホはカード）。声をかけたほうがいい人から順にならぶ。いま何をしているか、どれくらい続いているか、きょうの提出。しぼりこみつき。試作の時計を変えると様子も変わる（10:24 なら「24分 手が止まっています」が出る）
利用者の一覧 ジャンル・級・目標・きょうの出席・今月の出席率
利用者のくわしい様子 いまの様子と「声をかけた」、きょうの流れ、今月のカレンダーと時間のグラフ、提出したもの、ぴくとに聞いたことは話題だけ（中身は見せない。緊急の時だけ知らせが出る）、職員メモ（自動で保存）、声かけの記録
出席 日ごと（PCは表、スマホはカード。直す時は理由が必要）と、10月の一覧（名前の列が止まったまま横にスクロール）。CSV で保存（本当にファイルになる）・印刷
月の報告 事業所の10月のまとめ（のべ出席・平均の時間・授業LIVE・提出・運営OK、1日ごとの来た人数のグラフ）と、ひとりずつの報告。「本人のようす」「来月の目標」は AI が下書き → 職員が直して保存。「ふりかえりの材料です。福祉サービスの支援記録は事業所の様式で」と明記。A4 で印刷できる
授業の予定 週の時間割（きょう・いまの時間に印）、きょう参加しそうな人、これからのお知らせ
設定 文字の大きさ・ダーク・くっきり・動きをへらす（利用者とは別に保存）

運営（エスピクトスクール）

骨組み：PC は紺色のメニューで「仕事の道具」らしく。上に「確認待ち」の数。スマホは下に5つ（ホーム／提出チェック／配信／案件／もっと）。

画面 狙い
ホーム 確認待ちの数といちばん古い待ち時間、きょうの提出、使った人、授業LIVE、ぴくと相談、緊急の知らせ。14日分の提出のグラフ（表でも見られる）。「データの気になる所」：catalog.json で実際に見つかった 締め切り（10/11）が公開日（10/21）より前の課題3つ（「10/31にする」で直せる）、同じ題名の課題、web制作／Web制作 の書き方のまざり
提出チェック PC は3つの列：左に待ちの列（確認待ち／送った／出さない、AI の判定でしぼる。利用者が出したばかりのものは「いま届いた」）、まん中に提出物（種類に合った見本・ファイル・本人のひとこと・指示書のチェック項目・この人のこれまで）、右に AI の判定（よさそう／直す所あり／人の目で確認）と自信、理由、返事の下書き。下書きは やさしい日本語チェック（「修正してください」→「直してください」のように文が変にならない置きかえを1回で。合否のことば・長すぎる文も知らせる）。決めるのは 「OK（このまま送る）」「直してOK（直して送る）」「出さない」 の3つ。利用者に見せる表示（できた／直してね）も えらべる。キーボード 1/2/3・J/K・E・⌘Enter。送ったあとは「取り消す」ができ、つぎの1件へ自動で進む。OK の時だけ利用者に届く（届くと、利用者の課題のチャット・お知らせ・課題の表・作ったもの が変わる）
配信 課題（作り方×級の表に提出数・締め切りの注意、月の指示書は「表記をそろえた」印と元の題名、はじめてコース）、授業LIVE（時間割・アーカイブの数）、教材（シリーズ17・本数・長さ）
課題を作る ①まとまり名とジャンル ②作り方×級を表で選んで、まとめて作る（最大9つ）③指示書（やること3行・チェック）にも やさしい日本語チェック ④公開日・締め切り（締め切りが公開日より前なら先に進めない）・とどける先 ⑤確認。配信すると利用者の課題の画面とお知らせに届く
案件ボード 募集中・しめきり近い・準備中・練習用。手をあげた人（事業所・級・提出・OKの割合、条件に合うか）から「この人にお願いする」（取り消しもできる）。新しい案件は利用者の案件ボードにも出る。お金の表示はない
利用者・事業所 さがす・しぼる。事業所ごとの利用者、きょう来た人、最近の提出
納品 制作中 → 運営チェック → 納品待ち → 納品済み のボード。「つぎへ」「納品する」（取り消しもできる）

4. デザインの決まり

  • 色：公開ページ（espict-school.com）の水色をもとにしたブランド色。「つぎの一歩」は水色、授業LIVE はピンク、状態の色（できた＝緑、確認中＝黄、直す＝黄、緊急＝赤）は 必ずアイコンとことばといっしょ（色だけで伝えない）。文字と背景のコントラストは計算して 4.5:1 以上（WCAG AA）。
  • 文字：Windows では BIZ UDPゴシック（ユニバーサルデザインの書体）、iPhone・Mac ではヒラギノ。利用者の本文は 17px から（大きい 19px・とても大きい 22px）。行間はひろめ。日本語の折り返しを「ことばのまとまり」で（対応ブラウザ）。
  • 押せるところ：利用者の画面ではボタンの高さ 52px 以上。アイコンだけのボタンは作らない（必ずことばをそえる）。
  • ダーク・くっきり表示：色を「役わり」で決めているので、どの画面もそのまま切りかわる。くっきり表示は白黒＋太い線＋下線。
  • 動き：ひかえめ。「動きをへらす」設定や端末の設定で止まる。
  • グラフ：1つの系列はブランド色だけ、凡例はなし（題名で分かる）、細い棒、さわると値、「表で見る」で表にもなる。
  • ぴくと：水色の体に、ピンクのヘッドホン（公開ページの雰囲気から）。表情は「ふつう／にっこり／考え中」。

5. 安心・安全のための工夫

  • ぴくとは合否を言わない。「合格かどうかは運営の人が見て決めるよ。ぼくはヒントを出すね」と、チェック項目を いっしょに見る。
  • 体や気持ちのつらいことば（つらい・ねむれない・いやになった など）には、本人に「職員さんに知らせたよ」と伝えたうえで職員に知らせる。こっそり通報しない。
  • 職員は ぴくととの会話の中身を見ない（話題だけ）。緊急の知らせの時だけ、そのひとことを引用する。
  • 運営が OK するまで、AI の返事は利用者に届かない。「出さない」を選ぶと、何も届かない。
  • 依頼の決まりにそって、画面に出さないと決めたことばは使わない（このメモにも書いていません）。名前は「エスピクトスクール」、AI は「ぴくと」で統一。収入・工賃を約束する言い方をしない（案件ボードにお金の表示はない）。
  • 調子のチェックや「どうだった？」は 答えなくてもOK。
  • 試作のデータは端末の中だけ。外には送らない。

6. catalog.json の使い方と、気づいたこと

  • 使ったもの：教材のシリーズ17（パソコンの基本、STUDIO入門・中級、ブログ講座、かんたんブログ、AI版ブログ、ブログの画像、Web制作 基礎・応用、動画編集 基礎・応用、画像デザイン、フォトショップ、SNS運用）、授業LIVE の名前、アーカイブ94本（9月〜10月）、課題（10月のブログ記事9つ、月の指示書、はじめてコース6つ）。
  • 表記ゆれをそろえて表示：「web制作 指示書10月上級」→「Web制作 指示書 10月 上級」、全角数字など。元の題名も画面に小さく残す。
  • 気づいたこと（運営のホームと配信にも出しています）
    • STUDIO 版のブログ記事3つは、締め切り（10/11）が公開日（10/21）より前。利用者の画面では10月31日として見せ、運営には直す候補として知らせる。
    • 同じ題名の課題が複数ある（「【体験用】練習課題：自己紹介文をAIと整える」が7つ など）。
    • 古い教材の多くは長さが「60分」で、仮の値に見えるため、利用者には長さを出していない。
  • 架空のもの：人の名前・事業所・お店・会社・案件、指示書の中身（題名は本物）、AI の判定と返事の下書き、出席や時間の数字。
